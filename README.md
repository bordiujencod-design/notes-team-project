# Notes Team Project

- Bordiujenco Daniel
- Moroz Vlad

## Idee de proiect

Notes Team Project este o aplicație simplă pentru crearea și gestionarea notițelor. Utilizatorul poate adăuga notițe, le poate vedea într-o listă și le poate șterge atunci când nu mai sunt necesare.

Proiectul este realizat în limbajul **Kotlin**.

## Motivație

Am ales această idee deoarece notițele sunt utile pentru organizarea ideilor, temelor și sarcinilor. O aplicație de notițe ajută utilizatorul să păstreze informațiile importante într-un singur loc.

## Caracteristici

- Adăugarea unei notițe
- Afișarea notițelor
- Ștergerea unei notițe
- Interfață simplă
- Proiect ușor de folosit și de înțeles

## Componente necesare

Pentru realizarea proiectului sunt necesare:

- Calculator sau laptop
- Android Studio
- Limbajul Kotlin
- Emulator Android sau telefon Android
- GitHub pentru publicarea proiectului

Fiecare membru al echipei are un rol important în realizarea proiectului:

- **Bordiujenco Daniel** - creează structura aplicației și scrie codul principal în Kotlin.
- **Moroz Vlad** - realizează interfața aplicației și ajută la organizarea notițelor.

## Cum rulează proiectul

Pentru a rula proiectul:

1. Se deschide proiectul în Android Studio.
2. Se alege un emulator Android sau un telefon conectat la calculator.
3. Se apasă butonul **Run**.
4. Aplicația pornește și poate fi folosită.

## Rezultatul proiectului

Rezultatul proiectului este o aplicație simplă de notițe, realizată în Kotlin. Utilizatorul poate adăuga, vedea și șterge notițe. Proiectul ajută la înțelegerea bazelor programării în Kotlin și a dezvoltării unei aplicații Android.
